Product overview

The PK-200S is a tabletop impulse sealer that closes the opening of a bag by melting it with heat.

The PK-200S is a Tabletop Packaging Machine in the PK Series. It can seal bags made of materials such as polyethylene and polypropylene, up to a length of 200 mm.

When you place a bag at the sealing position and press the foot switch, the press bar comes down, and heating and cooling are performed automatically. You can work while supporting the bag with both hands.

The PK-200S has an automatic mode, in which a photoelectric sensor detects the bag and the machine seals it automatically. Because you do not need to press the foot switch, this mode is suitable for sealing the same type of bag continuously.

Features

  • The sealing temperature can be set in 5 °C steps, which gives a consistent finish.
  • The heating time and the cooling time can each be set in 0.1 second steps.
  • When a problem is detected, the machine shows an error code on the display and stops operation.
  • In automatic mode, the machine can seal up to 25 bags per minute.
