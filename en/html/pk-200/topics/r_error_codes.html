Error codes

When a problem is detected, the machine stops operation and shows an error code on the display.

To clear an error, remove the cause, turn off the power switch, wait at least 5 seconds, and then turn it on again.

Table 1. Error code list
Code Description Remedy
E-01 Heater wire is broken Replace the heater wire.
E-02 Sealing section has overheated Turn off the power switch, wait at least 10 minutes, and then turn it on again.
E-03 Temperature sensor error Turn the power switch off and on again. If the code appears repeatedly, the machine needs repair.
E-04 Press bar operation error Check that nothing is caught under the press bar.
E-05 Foot switch error Check that nothing is resting on the foot switch.
Note:
If the problem persists after you take the corrective action, stop using the machine and contact the dealer where you purchased it.
